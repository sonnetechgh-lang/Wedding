# Bernice & Richard Wedding Programme

A responsive wedding programme built with plain HTML and CSS.

## Preview locally

Open `index.html` directly in a browser, or run a static server from this directory:

```bash
npx serve .
```

## Deploy to Vercel

1. Commit and push every project file to the Git repository.
2. Import the repository in Vercel.
3. Use **Other** as the Framework Preset.
4. Redeploy. The checked-in `vercel.json` disables the build step and serves the repository root.

No database, server, environment variables, or build process is required.

## Main files

- `index.html` — page content and structure
- `styles.css` — layout, typography, colors, and responsive design
- `assets/` — portrait, monogram, floral artwork, and favicon
- `vercel.json` — static deployment settings
